## 五、Hero 标题说明

### 为什么用这个标题

```
不用写代码，不用学 Docker，不用看英文
选你想做的事，剩下的交给我们
```

**三「不用」结构**：
- 「不用写代码」→ 排除最大恐惧（"我不会编程"）
- 「不用学 Docker」→ 排除最大技术壁垒（竞品 awesome-selfhosted 的核心痛点）
- 「不用看英文」→ 差异化价值（中文用户专属痛点）

**「选你想做的事」** → 以用户需求为中心，不是以工具为中心
**「剩下的交给我们」** → 承诺可靠性，降低决策风险

### 之前考虑过但放弃的标题

| 标题 | 放弃原因 |
|------|----------|
| 「好工具，一键装到自己的电脑上」 | 「装」「电脑」隐含技术动作 |
| 「把你的电脑变成全能家庭服务器」 | 「服务器」是技术术语 |
| 「开源软件，从此不再难装」 | 「开源软件」是技术术语 |
