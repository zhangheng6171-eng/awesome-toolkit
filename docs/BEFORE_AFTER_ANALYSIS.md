# Before / After — UX Fix Pack 效果分析

> 日期：2026-06-08

---

## 1. Stirling PDF — 默认密码

| | Before | After |
|------|--------|-------|
| post_deploy_msg | 「拖文件进去就能用」 | 「首次访问会提示创建管理员账号（自己设置用户名和密码）」 |
| setup_notes | 无 | 3 条：创建流程 / 如何关闭安全模式 / 大文件内存建议 |
| 用户首次体验 | 看到登录页，不知道密码 → 放弃 | 看到账号创建页，自己设密码 → 成功 |
| **预期失败率** | ~50% | ~10% |

---

## 2. Vaultwarden — HTTPS 要求

| | Before | After |
|------|--------|-------|
| alternative_install | 「如需开启 HTTPS（推荐），建议配合 Nginx Proxy Manager」 | 「⚠️ 手机 App（iOS/安卓）要求 HTTPS。HTTP 仅适合电脑浏览器测试。如需手机用：Nginx Proxy Manager 或 Cloudflare Tunnel」 |
| setup_notes | 无 | 2 条：注册流程说明 + HTTPS 重要性强调 |
| 用户首次体验 | 电脑能用 → 下 App → 连不上 → 卸载 | 电脑能用 + 预先知道手机需要 HTTPS |
| **预期失败率** | ~30%（手机用户） | ~15%（有心理准备+方案） |

## 3. install.sh — 防火墙提示

| | Before | After |
|------|--------|-------|
| 防火墙相关信息 | 无 | 独立黄色警告区块，含云服务器安全组 + ufw 两种方案 |
| 端口提示 | 无 | 自动从 compose 文件解析并显示 |
| 用户体验 | 部署成功 → 打不开 → 以为部署失败 | 部署成功 → 打不开 → 看到提示 → 去安全组放行 → 成功 |
| **预期失败率** | ~20%（防火墙问题） | ~5% |
