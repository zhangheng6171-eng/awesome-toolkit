## 严重级别判断标准

### P0 — Critical（立即修复，阻塞上线）
- 网站白屏 / 500 错误
- 核心页面打不开（首页、部署列表、工具详情）
- API 全部不可用
- 安全漏洞（XSS、注入等）
- 数据丢失（KV 数据被误删）

### P1 — High（24 小时内修复）
- 核心功能有严重缺陷（如部署向导连接 Agent 总是失败）
- 重要页面有明显错误（工具详情信息错误）
- 移动端完全无法使用
- 搜索/筛选失效

### P2 — Medium（本周修复）
- 非核心功能有小问题（如复制按钮偶尔不工作）
- UI 不一致或显示异常
- 文案错误
- 性能问题（页面加载慢）

### P3 — Low（下个迭代修复）
- 美化类问题
- 极少数用户会遇到的边缘情况
- 功能建议

---

## 快速判断流程

```
发现了问题
    │
    ├─ 网站打不开 / 白屏？ ──────── P0
    ├─ 核心功能不能用？ ─────────── P1
    ├─ 功能能用但体验差？ ───────── P2
    └─ 小瑕疵 / 优化建议？ ──────── P3
```
