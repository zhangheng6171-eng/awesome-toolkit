# 首次用户测试计划

> 设计目标：真实用户在 30 分钟内完成测试
> 难度：无需技术背景
> 前提：用户有一台可 SSH 登录的 Linux 服务器（或愿意只看不操作）

---

## 测试前准备（给测试者）

### 你需要准备
- 一台电脑（手机也可以，但电脑体验更好）
- 浏览器（Chrome / Edge / Safari）
- （可选）一台 Linux 服务器 + SSH 客户端

### 你需要知道
- 这个网站是**早期测试版**，可能会有一些小问题
- 所有功能都是**免费**的，不需要付费
- 重点测试的是「浏览工具 → 一键部署」这个流程

---

## 30 分钟测试流程

### 第一阶段：浏览工具（10 分钟）

#### 任务 1.1：随便逛逛（3 分钟）
打开 https://awesome-toolkit.pages.dev

- [ ] 首页能正常打开吗？
- [ ] 能看到工具卡片吗？大概有几个？
- [ ] 页面加载速度怎么样？（快 / 一般 / 慢）
- [ ] 往下滚动，能看到"用户怎么说"和"订阅更新"吗？

**关注点：** 第一印象。页面看起来专业吗？文字能看懂吗？

#### 任务 1.2：搜索一个工具（2 分钟）
在顶部搜索框输入：`照片`

- [ ] 搜索结果出现了吗？有几个结果？
- [ ] 搜索结果和「照片」相关吗？
- [ ] 清空搜索框，工具列表恢复了吗？

**关注点：** 搜索功能是否准确、快速。

#### 任务 1.3：用筛选器（3 分钟）
- [ ] 点击左侧「筛选条件」，选一个分类（比如"自部署 & 家庭服务器"）
- [ ] 工具变少了吗？全是那个分类的吗？
- [ ] 再选一个难度（比如 ⭐⭐），进一步缩小范围
- [ ] 点「清除所有筛选」，恢复全部工具

**如果在手机上：** 顶部有一个横向滚动的筛选栏，左右滑动试试。

**关注点：** 筛选是否直观、组合筛选是否正常工作。

#### 任务 1.4：点进一个工具（2 分钟）
随便点一个工具卡片，进入详情页。

- [ ] 能看到工具名称、GitHub Star 数吗？
- [ ] 「使用步骤」能看懂吗？步骤多吗？
- [ ] 页面底部有「同类工具推荐」吗？
- [ ] 点「返回首页」或面包屑导航能回去吗？

**关注点：** 工具详情页信息是否完整、用词是否通俗。

---

### 第二阶段：尝试部署（10 分钟）

> 如果你没有服务器，可以只看页面，不实际操作。

#### 任务 2.1：进入部署列表（2 分钟）
点导航栏的「一键部署」或访问 https://awesome-toolkit.pages.dev/deploy

- [ ] 能看到多少个工具？有没有你认识的？
- [ ] 每个工具卡片显示了什么信息（名称、内存、磁盘）？
- [ ] 「准备条件」的 3 步说明清楚吗？

#### 任务 2.2：看一个部署详情（3 分钟）
点一个工具（建议选 Immich 或 N8n），进入部署详情页。

- [ ] 页面显示了部署命令吗？命令长不长？
- [ ] 有「环境变量」设置吗？能理解是干什么的吗？
- [ ] 「前置准备」中推荐的服务器信息有用吗？
- [ ] 点「开始部署向导」按钮，能进入下一步吗？

#### 任务 2.3：部署向导（5 分钟）
进入部署向导页面（/deploy/[工具名]/wizard）

- [ ] 步骤 1：安装 Agent 的说明清楚吗？
  - 命令能复制吗？（点复制按钮试试）
- [ ] 步骤 2：连接信息
  - 输入一个假的 IP（比如 192.168.1.1）和 Token（随便填）
  - 点「测试连接」—— 应该报错「连接失败」，这是正常的
  - 错误提示清楚吗？能看懂为什么失败吗？
- [ ] 步骤 3：确认配置
  - 能看到工具信息和配置预览吗？
- [ ] 界面操作
  - 「上一步」「下一步」按钮正常吗？
  - 能自由切换步骤吗？

**关注点：** 向导流程是否顺畅、错误提示是否友好、复制按钮是否工作。

---

### 第三阶段：其他功能（10 分钟）

#### 任务 3.1：工具对比（3 分钟）
回到首页，在工具卡片上点「+ 对比」按钮（选 2-3 个工具），然后点底部浮动的「开始对比」。

- [ ] 对比页面显示了哪些维度？够用吗？
- [ ] 表格/卡片能看清楚各个工具的差异吗？
- [ ] 在手机上表格显示正常吗？

#### 任务 3.2：定价页（2 分钟）
访问 https://awesome-toolkit.pages.dev/pricing

- [ ] 三个方案的区别清楚吗？
- [ ] 「锁定早鸟价」的邮箱表单能提交吗？
- [ ] 提交后显示了什么？

#### 任务 3.3：关于页 + 反馈（3 分钟）
访问 https://awesome-toolkit.pages.dev/about

- [ ] 项目理念清楚吗？
- [ ] 联系方式和 GitHub 链接有效吗？

访问 https://awesome-toolkit.pages.dev/feedback

- [ ] 表单能提交吗？
- [ ] 提交后显示了什么？

#### 任务 3.4：推荐工具（2 分钟）
回到首页，滚动到底部，点「推荐工具」按钮。

- [ ] 弹窗出现了吗？
- [ ] 表单内容清楚吗？
- [ ] 关闭弹窗正常吗？

## 测试观察点（给观察者，不给用户看）

| 观察点 | 说明 |
|--------|------|
| 首页加载时间 | 首次访问到可交互的时间 |
| 搜索响应 | 输入到结果显示的延迟 |
| 筛选操作 | 用户是否需要提示才知道怎么筛选 |
| 部署向导 | 用户是否卡在某个步骤 |
| 错误处理 | 用户遇到错误时的反应 |
| 移动端体验 | 手机上操作是否方便 |
| 术语理解 | 用户是否理解 "Agent"、"Token"、"Docker" |
