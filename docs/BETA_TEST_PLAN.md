## B. 必测 API（8 个端点）

### B1 — GET/POST/DELETE `/api/servers`

```
[ ] GET 返回用户服务器列表（认证用户）
[ ] GET 匿名用户返回空列表
[ ] POST 创建新服务器记录
[ ] POST 验证必填字段（host/name）
[ ] DELETE 删除指定服务器
[ ] KV 存储后重启 Worker 数据保留
```

### B2 — POST `/api/deploy/connect`

```
[ ] 正确 host+token 返回 success + hostname
[ ] 错误 token 返回 unauthorized + 401
[ ] 无效 host 返回连接失败
[ ] Agent 未启动返回超时错误
[ ] 频率限制：连续 11 次请求返回 429
```

### B3 — POST `/api/deploy/execute`

```
[ ] SSE 流式返回（Content-Type: text/event-stream）
[ ] docker-compose.yml 正确拉取
[ ] 环境变量替换生效
[ ] 部署成功后 KV 写入部署记录
[ ] 部署失败后返回错误信息
[ ] 缺少 toolId/host/token 返回 400
```

### B4 — GET `/api/deploy/history`

```
[ ] 认证用户返回自己的部署历史
[ ] 匿名用户返回空数组
[ ] 历史记录包含 toolId/host/timestamp/status
[ ] 按时间倒序排列
```

### B5 — POST `/api/waitlist`

```
[ ] 有效邮箱存储到 KV
[ ] 无效邮箱格式返回错误
[ ] KV key 格式正确（waitlist:xxx@xxx.com）
[ ] 重复订阅不报错
```

### B6 — POST `/api/feedback`

```
[ ] 反馈内容存储到 KV
[ ] 空内容返回错误
[ ] KV key 格式正确（feedback:timestamp）
[ ] 可选 email 字段
```

### B7 — GET/POST `/api/auth/upgrade`

```
[ ] GET 返回当前用户方案（认证用户）
[ ] GET 匿名用户返回 free
[ ] POST 更新用户方案
[ ] KV key 格式正确（user:email:tier）
```

### B8 — 频率限制中间件 `_middleware`

## C. 必测部署流程（端到端）

### 测试环境要求

- 1 台 Ubuntu 22.04 VPS（≥2GB 内存，≥20GB 磁盘）
- Docker 已安装
- 防火墙开放 9876 端口（Agent）

### C1 — Agent 安装流程

```
[ ] curl install-agent.sh | bash 成功执行
[ ] Python3 Agent 启动成功（端口 9876）
[ ] Token 生成并存放在 ~/.awesome-tools-agent-token
[ ] Token 权限 600（仅 owner 可读）
[ ] Agent 日志输出正常
[ ] 重启 VPS 后 Agent 是否能自动恢复（systemd 缺失已知限制）
```

### C2 — 一键部署流程（至少测 5 个工具）

**必测工具：**
1. **Immich**（最复杂：PostgreSQL + Redis + 多容器，4GB 内存需求）
2. **n8n**（中等：单容器，512MB 内存）
3. **Vaultwarden**（简单：单容器 + SQLite，256MB 内存）
4. **Uptime Kuma**（最简单：单容器，256MB 内存）
5. **Prometheus**（新增：Node Exporter 集成）

**每个工具测试：**
```
[ ] 向导 Step 0: Agent 安装说明清晰
[ ] 向导 Step 1: 测试连接成功（绿色勾）
[ ] 向导 Step 2: 环境变量可编辑（如适用）
[ ] 向导 Step 3: 实时日志流正常
[ ] 部署完成后显示访问 URL
[ ] 实际访问 URL 能打开服务
[ ] docker ps 确认容器运行
[ ] 健康检查通过
[ ] 数据目录已创建且有内容
```

### C3 — 卸载流程

```
[ ] 控制台展开服务器 → 点击卸载
[ ] 确认对话框弹出
[ ] 输入 Token 后卸载成功
[ ] docker ps 确认容器已删除
[ ] 数据目录已删除（docker compose down -v）
[ ] Agent 状态更新（get_deployed_tools 不再列出）
```

### C4 — 更新流程

```
[ ] 控制台点击更新
[ ] 新镜像拉取成功
[ ] 容器重启后服务正常
[ ] 数据未丢失
```
