## 长版介绍（用于 Product Hunt、V2EX、博客）

### 为什么做这个？

GitHub 上有成千上万个优秀的开源工具：Immich（照片管理）、N8n（工作流自动化）、Ollama（本地 AI）……但大多数工具的文档都是英文的，而且假设读者已经懂技术。

**普通人面对这些工具时的问题是：**
1. 不知道有什么好工具（发现门槛）
2. 看英文文档太累（语言门槛）  
3. 不知道怎么装到自己服务器上（技术门槛）
4. 装了不会用（使用门槛）

### Awesome Toolkit 解决了什么？

我们做了四件事：

**1. 精选** — 从 GitHub 海洋里捞出 50+ 强工具（Star ≥ 1000，有明确使用场景，有可用文档），覆盖 8 个分类。

**2. 翻译** — 每个工具用中文重写了描述和使用步骤。不是机翻，而是「如果我向我妈介绍这个工具，我会怎么说」。

**3. 一键部署** — 32 个工具支持一键部署。在你的服务器上安装一个轻量 Agent，然后点几下按钮，自动装好 Docker + 启动服务。5 分钟内从零到能用。

**4. 持续更新** — GitHub Actions 每天自动更新 Star 数，保持数据时效性。

### 适合谁？

- 有自己的 VPS/家庭服务器，但不想折腾 Docker 配置的人
- 对自托管感兴趣，但被英文文档劝退的人
- 想快速了解「有什么好用的开源工具」的人

### 技术栈

Next.js 16 + Cloudflare Pages + Cloudflare Workers + KV + Python Agent

## FAQ（预期常见问题）

**Q: 这个网站收费吗？**
A: 全部免费。我们可能在未来推出高级功能（如自动备份、监控告警），但基础功能永远免费。

**Q: 我需要懂 Docker 吗？**
A: 不需要。「一键部署」只需要你会复制粘贴命令。当然懂 Docker 更好，可以自定义配置。

**Q: Agent 安全吗？**
A: Agent 运行在你自己的服务器上，代码完全开源。它只执行白名单内的 Docker 命令，同一 IP 认证失败 5 次自动锁定 10 分钟。

**Q: 我的数据会传到你们的服务器吗？**
A: 不会。部署的工具运行在你自己的服务器上，Agent 只是帮你执行安装命令。我们看不到你的任何数据。

**Q: 怎么推荐新工具？**
A: 首页底部有「推荐工具」按钮，填写工具名称和理由即可，我们会审核后添加。
