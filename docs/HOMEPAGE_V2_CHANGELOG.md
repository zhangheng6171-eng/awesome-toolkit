| 旧蓝色 CTA 卡片（「不知道从哪个工具开始？」） | 被 Hero 区主 CTA 替代 |

| 导航栏副标题（「从全世界开源代码中...」） | 技术黑话，Hero 区替代 |
| 导航栏「收录标准：Star≥1000...」 | 非技术用户不需要知道 |
| Footer「工具数据来自 GitHub 公开仓库...」「收录标准：Star ≥ 1000...」 | 技术黑话 |

### 新增

| 模块 | 描述 |
|------|------|
| **Hero 区** | 主标题「不用写代码，不用学 Docker，不用看英文」+ 副标题「选你想做的事，剩下的交给我们」 |
| **主 CTA** | `🚀 告诉我用什么设备` → 大按钮，跳转 `/recommendations` |

| **场景区** | 4 张卡片：手机照片自动备份 (Immich) / AI 自动干活 (n8n) / 一个密码管理所有账号 (Vaultwarden) / PDF 文档处理 (Stirling PDF) |
| **热门标签** | 6 个标签：照片备份 / 密码管理 / 网站监控 / AI聊天 / PDF处理 / 去广告 |
